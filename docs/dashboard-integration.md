# 공개 운영 관리 화면 연결

2026-10-05 요청에 따라 마이크로사이트의 공통 헤더에 `운영 관리` 이동 링크를 추가합니다. 같은 탐색 메뉴가 데스크톱과 모바일에서 사용됩니다. 기존 네 메뉴의 순서와 서비스 소개 동작은 유지합니다.

대상은 독립된 회사 운영 대시보드입니다. 팀 생성·사원 등록과 이동·체험 이력 조회를 샘플 워크스페이스에서 둘러보는 서비스이며 실제 관리자 계정·방문객 개인정보·장치 제어가 마이크로사이트에 추가되는 것은 아닙니다. 실제 운영 API 연결·현장 장치 검증·공개 배포 완료를 뜻하지 않습니다.

## 주소 설정

`src/data/paths.ts`가 `VITE_DASHBOARD_URL`을 읽고 절대 HTTP(S) URL만 허용합니다. 잘못된 주소·상대 경로·javascript/data 프로토콜은 링크를 표시하지 않습니다. 이 값은 번들에 공개되므로 비밀값을 넣지 않습니다.

- 개발 환경에서 변수가 없으면 `http://127.0.0.1:4174/#/overview`를 사용합니다.
- 빈 값을 명시하면 개발 환경에서도 링크를 숨깁니다.
- 프로덕션은 기본 주소가 없습니다. 배포한 대시보드의 확인된 URL을 설정하고 다시 빌드해야 링크가 나타납니다.
- `.env.example`은 빈 값을 제공합니다. 로컬 `.env`는 Git에 넣지 않습니다.
- 새 탭 링크에 `noopener noreferrer`와 `샘플 워크스페이스 (새 탭)` 접근성 안내를 제공합니다.

## 로컬 확인

1. 별도 대시보드의 개발 서버를 `127.0.0.1:4174`에서 실행합니다.
2. 이 마이크로사이트에서 `npm run dev`를 실행하고 `http://127.0.0.1:5174`를 엽니다.
3. `운영 관리`를 누르면 새 탭에서 대시보드의 운영 개요가 열리는지 확인합니다. 모바일에서는 메뉴를 열고 같은 링크를 확인합니다.
4. 대시보드의 서비스 소개 이동 링크는 별도 대시보드 설정에서 현재 마이크로사이트 주소를 사용해 왕복을 확인합니다.

```sh
node tests/dashboard-url.mjs
npm run lint
npm run typecheck
npm run build
```

테스트는 개발 기본값, 프로덕션 기본 숨김, 명시적 빈 값, 올바른 HTTP(S) 주소, 위험하거나 불완전한 프로토콜을 확인합니다. 브라우저에서 360·390·768·1024·1280·1440px의 헤더, 키보드·Escape·모바일 메뉴와 새 탭 목적지를 별도 검증합니다. 실제 실행 결과는 최종 작업 보고에 기록합니다.

## 이 변경의 검증 기록

2026-10-05: `node tests/dashboard-url.mjs`, `npm run lint`, `npm run typecheck`, `npm run build`, `node tests/site-build.mjs`, `git diff --check` 통과. URL 검사는 현재 TypeScript 소스를 실행해 확인했으며 새 의존성을 추가하지 않았습니다. 이 기록에는 실제 브라우저 왕복·헤더 해상도 검사, 공개 배포나 실제 대시보드 서버 연동 검증은 포함되지 않습니다.

## 회사 관리 개편 연결 확인

2026-10-05: 헤더·자료 공개 영역의 이동 문구를 `운영 관리`로 통일했습니다. 팀·사원 관리 기능을 소개하고 샘플 워크스페이스의 데이터 범위를 유지합니다. 360·390·768·1024·1280·1440px에서 헤더의 링크 목적지와 문서 가로 넘침이 없는 것을 확인했습니다. 모바일 메뉴에서 새 탭으로 실제 로컬 대시보드(4174)에 이동하는 것을 확인했습니다. `npm run lint`, `npm run typecheck`, `npm run build`, `node tests/dashboard-url.mjs`, `node tests/site-build.mjs`, `git diff --check`를 재실행해 통과했습니다. 공개 대시보드 배포는 수행하지 않았습니다.
